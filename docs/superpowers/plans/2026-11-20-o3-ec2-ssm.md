# O3 EC2, EBS, Elastic IP và SSM Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Bổ sung runbook và mẫu IAM least-privilege để tạo EC2 ARM64, EBS 30 GB, Elastic IP và quản trị bằng SSM Session Manager.

**Architecture:** Tài nguyên thật được tạo trên AWS Console. Repository chỉ lưu hướng dẫn, policy mẫu có placeholder và lệnh kiểm tra; không lưu ID/ARN/account ID/secret thật. EC2 dùng instance profile gồm `AmazonSSMManagedInstanceCore` và policy runtime giới hạn theo SQS, Bedrock, Cognito User Pool và Parameter Store.

**Tech Stack:** Amazon Linux 2023 ARM64, EC2 `t4g.small`, EBS gp3, Elastic IP, IAM instance profile, Systems Manager Session Manager.

**Spec:** `docs/tasks.md` O3, `docs/context.md` mục 5.2, 5.3, 11 và `docs/aws-runbook.md` mục O3.

## Global Constraints

- Region: `ap-southeast-1`.
- EC2: `t4g.small`, ARM64; root EBS gp3 30 GB, encrypted.
- Không mở SSH; quản trị bằng SSM Session Manager.
- Không commit secret, access key, private key, account ID, resource ID hoặc ARN thật.
- Instance profile dùng quyền least-privilege; không cấp quyền IAM cho workload.
- Không tạo tài nguyên AWS trong quá trình sửa repository.

## Review Focus

- EC2 phải dùng ARM64 để khớp `t4g.small` và artifact `linux-arm64`.
- EBS phải là gp3, 30 GB và encrypted.
- Security Group không có inbound SSH; SSM hoạt động qua instance profile và outbound.
- Policy runtime phải dùng ARN placeholder, không dùng wildcard tài nguyên cho SQS/Cognito/SSM.
- Elastic IP phải gắn đúng EC2 và được ghi chú ngoài repository.
